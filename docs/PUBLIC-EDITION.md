# Public edition

This is a new, independent Git history containing only the reviewed software and operating documentation. The older development repository is private and archived; its commits, PR references and mechanical files were not imported.

Included: both ESP32 source targets, hub/panel, voice/Android code, tests and contributor documentation. Excluded: real credentials, personal compiled firmware, local runtime data, mechanical design files and third-party song transcriptions.

The public edition uses original sound motifs Pulse, Lunar March, Arcade and Cosmos. The private robot firmware was not overwritten or flashed during publication. Public source changes must be built and tested before any future hardware update.

The root [README](../README.md) credits miniRobo K9V2.1 as the original base; [THIRD_PARTY.md](../THIRD_PARTY.md) records upstream terms, which are not superseded by this repository's MIT license for original contributions.
