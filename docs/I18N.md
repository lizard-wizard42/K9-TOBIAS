# Internationalisation (i18n)

The K9 interface is available end to end in **Português (pt-BR), English, Español, Français, Deutsch and 中文 (普通话, zh-CN)**.

| Layer | What is translated | Where it lives |
| --- | --- | --- |
| Control panel (browser, PC and phone) | every visible text, tooltips, accessibility labels, messages, toasts, confirmation dialogs, document title, `<html lang>` | `k9_control_hub/public/i18n/` |
| Language picker | selector at the top of the panel; choice saved in `localStorage` (`k9.lang`); first visit follows `navigator.languages`; falls back to Portuguese | `i18n/i18n.js` |
| Voice commands | stop words, name handling and commands (sit, lie down, stand, dance, stretch, wag, dig, paws, light on/off, forward/back/left/right, come here) for en, es, fr, de, zh; Portuguese stays in `voice-nlu.js` | `i18n/voice-lexicon.js` |
| Speech recognition and synthesis | the browser's recogniser (`rec.lang`) and, in the Android app, `SpeechRecognizer`/`TextToSpeech` use the selected language | `nome-voz.js`, `MainActivity.kt` (`K9App.idioma`) |
| Vivo page and gateway | UI, recogniser/voice language, stop/arm/disarm phrases, simple commands and the language the AI answers in | `k9_vivo/web/index.html`, `src/cerebro.js`, `src/agent.js` |
| Android app's own screens | error page, address dialog, toast (follow the phone's system language) | `k9_vivo/android/app/src/main/res/values-*/strings.xml` |
| Hub messages | the hub returns error *codes* (`ssid`, `senha`, `placa_offline`, …) and the panel translates them | `public/wifi-config-ui.js`, `strings-*.js` |
| Documentation | English (this repository's documentation language) | `docs/`, `README.md` |

## How it works

Portuguese is the **source language**: the Portuguese text is the dictionary key (a gettext-style approach). A row is `[pt, en, es, fr, de, zh]`:

```js
[`Sentar`, `Sit`, `Sentarse`, `S'asseoir`, `Sitz`, `坐下`],
[`Enviado: {0}`, `Sent: {0}`, `Enviado: {0}`, `Envoyé : {0}`, `Gesendet: {0}`, `已发送：{0}`],
```

- Dictionary files: `public/i18n/strings-ui.js` (static page text), `strings-dyn.js` (messages written by JavaScript, gaits), `strings-extra.js` (Wi‑Fi, name and voice, NPC mode, Vivo). They register rows in `window.K9Strings`.
- `{0}`, `{1}`… mark values. A key with placeholders works as a **template**: any sentence that fits it is translated, and arguments that are themselves known phrases are translated too (`Enviado: Sentar` → `Sent: Sit`).
- **The DOM is translated automatically**: text nodes plus `title`, `aria-label`, `placeholder` and `alt`. A `MutationObserver` also translates what JavaScript writes later, so most code does not call the translator. The original Portuguese is remembered, so switching language never degrades the text.
- Text that code composes from several parts must call `K9I18n.t(key, ...args)` explicitly and re-render on the `k9:lang` event (see `nome-voz.js`, `npc.js`, `wifi-config-ui.js`, `marcha-variacoes.js`).
- Add `data-no-i18n` to anything that must never be translated (robot name, log, language names). `<pre>`, `<script>`, `<style>`, `<code>` and `<textarea>` are skipped automatically.
- Untranslated text falls back to Portuguese, so nothing disappears from the screen.

## Adding or fixing a translation

1. Find the Portuguese row in `public/i18n/strings-*.js` (or add one) and edit the column of the language.
2. Keep the same `{n}` placeholders in every column; numbers use the local convention (`1,5` in pt/es/fr/de, `1.5` in en/zh).
3. Run `cd k9_control_hub && npm test`. `test/i18n.test.js` fails when a row has an empty column, different placeholders, a repeated key, a long text left untranslated, or when text in `index.html` is missing from the dictionary.

## Adding a language

1. Add `{ code, tag, name }` to `LANGS` in `i18n/i18n.js` and one column to every dictionary row (the tests enforce it).
2. Add the language to `L` in `i18n/voice-lexicon.js` (stop words, negations, intro words, one rule per command) and to the cases in `test/voice-lexicon.test.js`.
3. Add the tag to `idiomasPermitidos` in `MainActivity.kt`, a `res/values-<code>/strings.xml`, and the language to `IDIOMAS` in `k9_vivo/src/cerebro.js` and `IDIOMA_RESPOSTA` in `k9_vivo/src/agent.js`.
4. Check fonts for the new script (the panel's font stack already falls back to CJK system fonts).

## Voice commands per language

"Stop" is recognised **first and in any sentence**, with or without the robot's name, in every language (false positives are cheap, false negatives are dangerous). Short words that are also prepositions ("para" in Spanish) only count as a stop when they are the whole phrase. A negation anywhere ("don't sit", "nicht", "不要") cancels the command. Examples:

| | English | Español | Français | Deutsch | 中文 |
| --- | --- | --- | --- | --- | --- |
| stop | stop · halt · enough | alto · basta · para | stop · arrête · assez | Stopp · halt · genug | 停 · 别动 · 够了 |
| sit | sit down | siéntate | assis | Sitz | 坐下 |
| lie down | lie down | échate | couche-toi | Platz | 趴下 |
| stand | stand up | levántate | debout | steh auf | 站起来 |
| dance | dance | baila | danse | tanz | 跳舞 |
| paw | give me your paw | dame la pata | donne la patte | gib Pfote | 握手 |
| light | turn on the light | enciende la luz | allume la lumière | Licht an | 开灯 |
| walk | walk forward | camina hacia adelante | avance tout droit | geh vorwärts | 向前走 |
| come | come here | ven aquí | viens ici | komm her | 过来 |

Chinese has no spaces, so the rules look for fragments inside the sentence; the robot's name is matched as a fragment (speech engines often write it in Latin letters).

## Known limits

- Translations were written by the project's maintainers/assistants, not by professional translators. Native-speaker corrections are very welcome (open an issue or a pull request).
- The AI's free-form answers follow the selected language only as far as the model complies.
- Long engineering study documents under `docs/relatorio-engenharia/` (a generated historical report) remain in Portuguese.
