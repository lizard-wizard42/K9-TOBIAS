## Model permissions

The owner's intended model policy is **personal, non-commercial use**, with separate commercial-print permission through their MakerWorld membership. Confirm the exact listing and membership terms before selling prints. The repository's software license does not grant model rights, and no model file is relicensed by this document.

The robot's mechanical design has miniRobo K9V2.1 ancestry. Resolve upstream rights before publishing derivative model files or including them in a paid commercial membership; see [the public-edition notes](PUBLIC-EDITION.md).

## Publishing the model and print profile

Use one model page with the whole robot. Present the A1 multi-plate project as one complete profile. Keep the generic STLs together as model files, rather than separate model listings for individual robot parts. The Ender project belongs with the model's supplemental files, not as a Bambu printer profile.

For a print profile, use original photos of the complete parts printed with that exact profile, including matching colors and color regions. A photo of a robot built using a different printer/profile does not validate the A1 profile. Enter actual slicer estimates and settings after reviewing the profile; do not invent duration or material consumption.

Official guidance: [MakerWorld Print Profile Upload Guidelines](https://wiki.bambulab.com/en/makerworld/tutorials/print-profile-upload). MakerWorld exclusivity and commercial-membership eligibility depend on the platform's current terms and on owning the rights to the uploaded material; no enrollment was performed by this repository review.
